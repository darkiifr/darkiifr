### Projets en cours

**[Fiip](https://fiip.fr)**
App de prise de notes multi-plateforme : ordinateur, web, mobile et extension navigateur.

**[Caltemp](https://github.com/darkiifr/Caltemp)**
Calendrier de bureau, local et sans collecte de données.
- Vues année, mois, semaine et jour, récurrences, rappels natifs, import et export ICS
- SDK d'extensions (thèmes et plugins JavaScript) avec un registre public sur GitHub

**AzurBus** ( Not Actually Open Sourced )
App de transports en commun basée sur l'open data Lignes d'Azur, à Nice.

**Vins Sans** ( Not Actually Open Sourced )
Police d'interface maison de Vins Studio, variable de 100 à 900, dérivée d'Inter (OFL).
